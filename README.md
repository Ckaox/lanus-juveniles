# Lanús Juveniles Web App

Este proyecto es una aplicación web para gestionar y visualizar información de las divisiones inferiores del Club Lanús (de cuarta a novena división).

## Estructura del proyecto
- `frontend/`: Aplicación React (UI responsive para escritorio y móvil)
- `backend/`: API Node.js + Express (servidor y lógica de negocio)

## ¿Qué incluye?
- Resultados de fechas actuales y anteriores
- Seguimiento en vivo de partidos (marcar goles, tarjetas, etc.)
- Estadísticas de jugadores y partidos
- Roster de cada categoría
- Tablas globales y por categoría

## Cómo iniciar el proyecto

### 1. Backend
1. Ve a la carpeta `backend`:
   ```sh
   cd backend
   ```
2. Instala dependencias:
   ```sh
   npm install
   ```
3. Inicia el servidor:
   ```sh
   npm run dev
   ```

### 2. Frontend
1. Ve a la carpeta `frontend`:
   ```sh
   cd frontend
   ```
2. Instala dependencias:
   ```sh
   npm install
   ```
3. Inicia la app:
   ```sh
   npm start
   ```
